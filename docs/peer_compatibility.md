# Where to look before porting a graphics fix

Reviewed 24 November 2026. Check the parent, ProjectLeonida/Leonida (formerly ItsNotRexed/Leonida), first for each measured blocker. Search the default branch and the pull requests. An unmerged PR can contain the exact fix. Record the revision, author, affected file, what the patch actually implements and which Palmwave test exercises it. The [provenance ledger](../UPSTREAM.md) identifies code already incorporated. The [boot measurements](../STATUS.md) identify what the local executable actually reached.

## Current decisions

| Measured call | Existing work | Palmwave decision |
|---|---|---|
| Device 41, indirect type 105 | mrp1no documented two compute call sites that use three argument words. [Parent PR #7163, head 084c8c6](https://github.com/ProjectLeonida/Leonida/pull/7163), [FiveStar corroboration](https://github.com/ThatRecompDev/five-star-recomp/blob/b1ac4037d29a17f150f0cd03c9ba4aee69e6098e/src/FiveStar.Loader/Shims/D3D12X/XboxDeviceCreation.cs) | **Adapted from #7163** in [09b5735](https://github.com/fablinoo/palmwave/commit/09b5735). Palmwave translates the single 12-byte argument only for the observed node mask and absent root signature. The CPU mock checks that the caller retains its original descriptor. The RTX 5080 executable then created its first four signatures. Queue scheduling and execution of this signature remain unverified. |
| Device 41, fifth signature, mesh dispatch | [#7330, efc3478](https://github.com/ProjectLeonida/Leonida/pull/7330) implements signature creation. [#3777, f8b1978](https://github.com/ProjectLeonida/Leonida/pull/3777) includes indirect mesh replay and GPU fixtures. [#9222, 07f6da0](https://github.com/ProjectLeonida/Leonida/pull/9222) retries as ordinary compute dispatch. | **Evaluate #3777** against the RTX 5080 mesh path. The fifth signature returned unsupported. Creating an object alone leaves replay open. The compute substitution would change the pipeline that executes the command. No mesh patch incorporated in this audit. |
| Device 70, two R16_UINT buffer views | Etr0p's [#9068, 3959b38](https://github.com/ProjectLeonida/Leonida/pull/9068) builds typed and structured views and can import title-owned pages. Earlier [#8304, 56d2f04](https://github.com/ProjectLeonida/Leonida/pull/8304) looks up existing buffer ranges. | **Candidate with a known mismatch.** One caller requests 378 elements in a 768-byte resource. Using all available bytes exposes 384 elements. Preserve the caller's count, check the complete view against its backing resource and verify out-of-range reads. The original 174 MiB RAW view now succeeds independently. No typed-view fix incorporated in this audit. |
| Device 61, sampler creation | mrp1no identified CreateSamplerX in [parent #7115, 8f756eb](https://github.com/ProjectLeonida/Leonida/pull/7115). Five-star-recomp describes separate console filter and address fields in its [sampler layout](https://github.com/ThatRecompDev/five-star-recomp/blob/b1ac4037d29a17f150f0cd03c9ba4aee69e6098e/src/FiveStar.Loader/Shims/D3D12X/Resources/ConsoleSamplerDescription.cs). | Our private RTX 5080 diagnostic reached this call and resolved the host fault to desktop CreateMetaCommand. The parent route casts a console prefix to a desktop description. Verify the fields and sampler heap before adopting a decoder. |
| Direct mesh validation during pipeline statistics collection | [Parent #7112, 9e9bb63](https://github.com/ProjectLeonida/Leonida/pull/7112) addresses the clipping counters forbidden by [Vulkan VUID 07076](https://docs.vulkan.org/refpages/latest/refpages/source/vkCmdDrawMeshTasksEXT.html#VUID-vkCmdDrawMeshTasksEXT-pipelineStatistics-07076). | Reproduced three validation errors in the synthetic direct mesh test on RTX 5080. The peer uses generated primitives for both clipping statistics. Matching counts for an unclipped triangle leaves clipped geometry unverified. The executable has yet to reach mesh replay. |

These parent PRs were closed without a recorded merge at review time. Review their changes relative to the pinned head before porting stacked PRs. For fixes developed here, ProjectLeonida is the first upstream candidate. Record the coordination issue before submitting a parent PR.
